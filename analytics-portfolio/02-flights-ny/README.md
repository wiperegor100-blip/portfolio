# Flights NY — статистический анализ рейсов

Учебное задание по данным о рейсах из Нью-Йорка за 2013 год (датасет nycflights13).

## Данные
`data/flights_NY.csv` — ~336 тыс. рейсов: авиакомпания, борт (`tailnum`), задержки, время в воздухе, дистанция, аэропорты. Перед анализом убираю строки с пропусками и считаю `speed = distance / (air_time / 60)`.

## Что делал
Пять заданий, каждое в структуре «что исследуем → метод → вывод» (`notebook.ipynb`):
1. Вероятность задержки вылета по авиакомпаниям с парком >200 самолётов.
2. Распределение среднего времени в воздухе по бортам + 95% диапазон (μ ± 1.96σ).
3. t-тест: значимо ли различается средняя скорость WN и UA, с доверительными интервалами.
4. Связь средней скорости и дальности маршрута — полиномиальная регрессия 2-й степени.
5. Кластеризация парка (K-Means) по скорости и числу рейсов.

## Выводы
- Среди крупных парков чаще всех задерживается **WN** — ~54% вылетов с положительной задержкой.
- Среднее время в воздухе ~157 мин при σ≈76 — самолёты сильно неоднородны по типичным маршрутам.
- Скорость **UA выше WN** (423 против 398 mph), p-value практически ноль — различие значимо.
- Скорость и дальность связаны нелинейно: модель 2-й степени даёт R²≈0.80, быстрые борты обслуживают дальние маршруты.
- K-Means выделяет 4 интерпретируемые группы: быстрые дальние, медленные ближние, интенсивно летающие, редкие.

## Оговорка
Число кластеров `k=4` выбрано по методу локтя и интерпретируемости — явного «локтя» на графике нет, так что выбор частично экспертный.
