# Analytics Portfolio — Егор

Кейсы по анализу данных. Ищу позицию junior аналитика.

## Стек
Python (pandas, numpy), matplotlib, seaborn, scipy, scikit-learn, Jupyter.
Методы: EDA, когортный анализ, проверка гипотез (t-тест, доверительные интервалы), регрессия, кластеризация.

## Кейсы

| # | Кейс | О чём | Методы |
|---|------|-------|--------|
| 01 | [Business Travel](01-business-travel) | Анализ бронирований корп. travel-сервиса: GMV, концентрация, отток, когорты | EDA, когорты, проверка гипотез |
| 02 | [Flights NY](02-flights-ny) | Статистика по рейсам из Нью-Йорка (nycflights13) | t-тест, ДИ, регрессия, K-Means |

Каждый кейс — отдельная папка: `README.md` (задача → что делал → вывод), `data/`, `notebook.ipynb`, `charts/`. Ноутбуки запускаются сверху вниз.

## Запуск
```bash
pip install -r requirements.txt
jupyter notebook
```
