# Аналитические кейсы

Код, данные и выводы. Каждый кейс запускается сверху вниз и заканчивается выводом, а не пересказом метода.

[← Всё портфолио](..) · [Продуктовые кейсы →](../product-portfolio)

## Стек
Python (pandas, numpy), matplotlib, seaborn, scipy, scikit-learn, Jupyter.
Методы: EDA, когортный анализ, проверка гипотез (t-тест, доверительные интервалы), регрессия, кластеризация.

## Кейсы

| # | Кейс | О чём | Методы |
|---|------|-------|--------|
| 01 | [Business Travel](01-business-travel) | Анализ бронирований корп. travel-сервиса: GMV, концентрация, отток, когорты | EDA, когорты, проверка гипотез |
| 02 | [Flights NY](02-flights-ny) | Статистика по рейсам из Нью-Йорка (nycflights13) | t-тест, ДИ, регрессия, K-Means |
| 03 | [Прогноз продаж в агентстве](03-sales-forecast) | На каком уровне прогноз вообще возможен при 3–5 сделках в месяц | симуляция, 20 прогонов, WAPE, усадка к среднему, сравнение с baseline |
| 04 | [Экономика холодного канала](04-lead-economics) | Реальная воронка за год в CPA-агентстве: конверсии, стоимость сделки, рычаги роста | воронка, юнит-экономика, анализ чувствительности |

Каждый кейс — отдельная папка: `README.md` (задача → что делал → вывод), `data/`, `notebook.ipynb`, `charts/`. Ноутбуки запускаются сверху вниз.

## Запуск
