# VK Rollout Audit

Короткий аудит по запуску SportSchool Bot в VK.

Цель документа:

- понять, стоит ли идти в VK сейчас
- выбрать правильный первый формат запуска
- не пытаться переносить весь Telegram UX один в один
- использовать VK и как канал роста, и как будущий продуктовый канал


## Короткий вывод

Запуск в VK реалистичен и для проекта перспективен, но правильный первый шаг — не полный клон Telegram-бота.

Оптимальный порядок:

1. VK как канал привлечения и входа
2. VK как простой родительский кабинет и уведомления
3. VK как ограниченный рабочий интерфейс
4. только потом — полный перенос тренерского сценария

Причина простая:

- `core/` уже достаточно отделён от Telegram
- основная сложность живёт не в бизнес-логике, а в Telegram-специфичных хендлерах
- самый дорогой и рискованный сценарий в переносе — тренерская отметка посещаемости по фото


## Что Уже Готово Архитектурно

Сильные стороны проекта:

- `core/` не зависит от Telegram и уже содержит важные бизнес-потоки
- распознавание, подтверждение тренировки, списания, логи и часть аналитики живут вне UI
- есть база для multi-channel развития через адаптеры
- есть event log, что полезно для VK-кабинетов, аналитики и API

Ключевые модули, которые уже помогают запуску в VK:

- `core/pending_training.py`
- `core/attendance.py`
- `core/notifications.py`
- `db/repository.py`
- `recognition/*`

Это означает:

- переносить ядро несложно
- можно строить VK-адаптер поверх существующей логики


## Что Пока Сильно Завязано На Telegram

Самые Telegram-centric части:

- `bot/main.py`
- `bot/handlers/*`
- `ConversationHandler`
- `callback_data`
- `edit_message_text`, `reply_text`
- `PicklePersistence`
- inline-навигация и экранная логика меню

Это значит, что в VK нельзя просто “переключить SDK”.
Нужно делать отдельный адаптер интерфейса.


## Варианты Запуска В VK

### Вариант 1. VK как канал привлечения

Что даём:

- описание продукта в сообществе
- лид-форму
- кнопку “Начать”
- простого VK-бота для знакомства
- переход в Telegram или заявку на подключение

Сложность: низкая

Польза:

- быстро проверяем спрос
- можно собирать руководителей секций и родителей
- почти не трогаем основную систему

Минус:

- это ещё не второй рабочий канал продукта


### Вариант 2. VK как родительский кабинет

Что даём:

- привязка ребёнка
- остаток занятий
- история посещений
- расписание
- уведомления
- заявка на оплату или инструкция по оплате

Сложность: низкая-средняя

Польза:

- хороший канал для родителей
- понятная ценность для студии
- меньше риска, чем перенос тренерского сценария

Минус:

- основная рабочая операционка всё ещё остаётся в Telegram


### Вариант 3. VK как урезанный рабочий бот

Что даём:

- группы
- список учеников
- простая отчётность
- часть админских сценариев

Сложность: средняя

Польза:

- продукт начинает жить как multi-channel

Минус:

- придётся повторно проектировать много экранов и navigation flow


### Вариант 4. Полный VK-бот для тренеров

Что даём:

- выбор группы
- загрузка группового фото
- подтверждение распознавания
- ручные исправления
- списание
- undo

Сложность: средняя-высокая

Польза:

- почти полный паритет с Telegram

Минус:

- самая дорогая часть
- выше риск UX-проблем
- больше всего платформенной специфики


## Что Переносить В VK В Первую Очередь

Рекомендуемый первый объём:

1. сообщество VK + описание продукта
2. лид-воронка для руководителя
3. родительский кабинет
4. уведомления и базовая история ребёнка

Почему именно так:

- это быстрее запустить
- это полезно для роста аудитории
- это не ломает текущий Telegram-пилот
- это даёт продукту присутствие в VK без тяжёлого переписывания


## Что Пока Лучше Оставить В Telegram

На текущем этапе лучше оставить в Telegram:

- тренерский сценарий отметки посещаемости
- сложное подтверждение распознавания
- быстрые исправления после фото
- сценарий `undo`
- тяжёлые рабочие потоки с большим количеством inline-веток

Причина:

- они уже работают
- они критичны для пилота
- ошибка в них бьёт по доверию и списаниям


## Самый Правильный VK MVP

Лучший MVP для текущего этапа:

- VK сообщество продукта
- VK-бот для знакомства и заявки
- VK-родительский кабинет
- уведомления родителям в VK
- кнопка или сценарий перехода в рабочий канал

Такой MVP:

- помогает собирать ЦА
- даёт понятную пользу
- не требует полного дублирования Telegram-бота


## Что Нужно Для Полноценного Запуска В VK

Минимальный технический набор:

- отдельный `vk/` или `integrations/vk/` adapter
- обработчик входящих событий VK
- слой хранения пользовательской сессии для VK
- VK-уведомления через отдельный notifier/adapter
- VK-версии меню и экранов
- слой маппинга ролей и auth flow под VK user id

Желательно до полноценного запуска:

- вынести ещё больше сценарной логики из `bot/handlers/` в `core/`
- унифицировать состояния экранов
- отделить transport-specific тексты от бизнес-логики


## Основные Риски

- попытка перенести весь Telegram UX сразу
- перегруженный VK-бот без чёткого MVP
- дублирование логики вместо адаптера
- различия в авторизации и навигации между Telegram и VK
- распыление команды между работающим Telegram-пилотом и большим VK-рефакторингом


## Потенциал Для Роста ЦА

VK особенно полезен для:

- привлечения руководителей секций и студий
- присутствия в привычной российской площадке
- родительского канала
- контента, кейсов и доверия
- первых заявок без необходимости сразу ставить Telegram

VK менее полезен как первый полный рабочий инструмент для тренера, если Telegram уже хорошо работает.


## Рекомендация

На текущем этапе не идти в полный VK-клон Telegram-бота.

Идти так:

1. оставить Telegram основным рабочим каналом
2. сделать VK каналом роста и доверия
3. запустить VK-кабинет для родителей
4. после этого решать, нужен ли VK-рабочий интерфейс тренера


## Оценка Сложности

- VK как лид-канал: низкая
- VK как родительский кабинет: низкая-средняя
- VK как частичный продуктовый канал: средняя
- VK как полный рабочий канал тренера: средняя-высокая


## Следующий Практический Шаг

Следующий разумный шаг для проекта:

сделать отдельный документ с точным VK MVP:

- кто первый пользователь: родитель / руководитель / тренер
- какие 3-5 сценариев входят в первую версию
- что остаётся только в Telegram
- какие экраны и события нужны для запуска
